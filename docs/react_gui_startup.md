# 新人价自动化工作台 React MVP 启动说明

## 当前定位

当前 React MVP 是“新人价自动化工作台”的前端壳，用于展示批次状态、关键文件、日志异常和低风险入口。

本版本只读取配置、批次清单、输出文件和日志，不会在页面中执行筛品、查价、Outlook 下载、后台提报或审核回填。

## 启动方式

### 推荐：一键启动工作台

在项目根目录双击：

```bat
run_workbench.bat
```

该入口会分别打开两个窗口：

- 只读 Python API：提供 `/api/dashboard` 等接口。
- React 前端：提供工作台页面。

启动后访问：

```text
http://localhost:8443/
```

`run_workbench.bat` 不会执行筛品、查价、Outlook 下载、后台提报或审核回填，只负责启动工作台展示层。

### 单独调试入口

如果需要单独排查 API 或前端问题，可以分开启动。

#### 1. 启动只读 API

在项目根目录双击：

```bat
run_gui_api.bat
```

启动后 API 地址为：

```text
http://127.0.0.1:8765
```

健康检查接口：

```text
http://127.0.0.1:8765/api/health
```

#### 2. 启动前端页面

在项目根目录双击：

```bat
run_frontend.bat
```

启动后浏览器访问：

```text
http://localhost:8443/
```

如果脚本提示找不到 `npm`，请确认 `run_frontend.bat` 里的 `NODE_HOME` 指向本机 Node.js 解压目录。

## 启动脚本关系

```text
run_workbench.bat  = Demo 工作台总入口，只启动 API + 前端
run_gui_api.bat    = 只读 Python API 单独调试入口
run_frontend.bat   = React 前端单独调试入口
run.bat            = 原有命令行业务工具，保持不变
```

页面中的“启动命令行入口”只会打开 `run.bat`，不会自动选择菜单或执行高风险动作。

## 已接入的真实数据

- 批次名、批次日期、运行环境提示。
- 输出目录、日志目录、批次清单路径。
- 5 个流程阶段状态：准备任务、筛品查价、业务确认、后台提报、审核回填。
- 关键文件状态：新人价整合表、查价失败 SKU、ERP 文本、提报 PART 文件目录、提报情况整理表、批次清单、日志目录、疑似误下载目录。
- 品池概览：从最新提报情况整理表中读取汇总指标，读取失败时显示不可用状态。
- 底部日志：读取最新日志文件和异常关键词。

## 当前仍是低风险入口

- 打开文件/目录：调用本地 API 打开已有路径。
- 复制 ERP 文本：仍由前端剪贴板完成。
- 启动命令行入口：只打开现有 `run.bat`，不自动选择菜单或执行高风险流程。

## 未做功能

- 不在 GUI 中执行真实提报。
- 不做一键完整运行。
- 不展示完整 SKU 明细。
- 不修改核心筛品、查价、Outlook 下载、后台提报和 `main.py` 工作流。
